标题：做了一个给普通人看的 GitHub 日报生成器：零依赖、30 天去重、可选 AI

最近在整理「普通人到底能从 GitHub 得到什么」这个问题，顺手做了个小工具。

市面上的 GitHub 精选大多还是面向开发者：框架、SDK、命令行工具、自托管服务。对不写代码的人来说，点进去往往第一步就劝退了。

所以我换了个筛选口径：只留学习、生活、效率、健康、财务这五类里，普通人真的能用上的项目，并且明确过滤开发者基础设施。

它每天做的事情大概是：

- 用几组关键词去 GitHub 搜近期新建 / 近期有更新的项目
- 过滤掉无描述、教程合集、SDK / library / framework、fork 比异常的项目
- 30 天内推荐过的项目不重复推；只是见过但没选上的，冷却 7 天
- 每个领域最多 3 个，避免整份日报全是「生活」
- 打分排序，生成中文 Markdown + 一个自包含的 HTML 页面
- 可选：调用任意 OpenAI 兼容接口，把文案写得更具体；不配置也能跑

技术上没什么花活：纯 Python 标准库，零依赖。Windows 双击 `运行日报.bat`，macOS/Linux 跑 `./run.sh`。也带了 GitHub Actions，可以每天定时跑并发布到 Pages。

它不是什么：

- 不是人工精选，筛选是启发式的，质量会有波动
- 不保证每天都有 10 个，宁缺毋滥
- 不会自动安装任何被推荐的项目
- 和 GitHub 官方没有关系
