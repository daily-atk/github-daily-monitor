## 发布顺序建议

1. **V2EX（分享创造）** —— 反馈最快，适合先验证表达是否清楚。
2. **少数派** —— 需要更完整的图文和首发说明，建议在 V2EX 反馈后修改一版再投。
3. **Reddit** —— 英文受众，先选一个最匹配的 subreddit，不要一次铺开。

## 回复原则

- 不删负评，先承认局限：启发式筛选、质量有波动、AI 可选。
- 不承诺做不到的事（例如“保证每天 10 个精品”）。
- 有人报 bug 时，附上系统和日志位置，不要贴 token。
- 不主动求 star；把“愿意试用/提 issue”放在前面。
