# 即刻日更模板

## 平台特点

- 短：1–3 段，几百字；不需要标题
- 语气：像跟朋友说话，真实、具体；不要营销腔
- 配图 1–3 张（日报截图或项目卡片）
- 可以放链接；如果互动低，把链接放第一条评论
- 适合的圈子：一起做产品、工具推荐、独立开发、GitHub
- 发布时间：12:00–14:00 或 21:00–23:00

## 日更模板（主推荐）

```
今天份的 GitHub 日报：挑了 {N} 个普通人能用的项目。

最想推荐 {项目名}：{一句话功能}。适合{人群}，{平台}，{许可证}。

另外几个：
· {项目名}：{一句话}
· {项目名}：{一句话}
· {项目名}：{一句话}

每天自动更新，零依赖开源：{链接}

求拍砖：你觉得「普通人能用」最该看什么——免费、手机能用，还是不用配置？
```

### 今日示例

```
今天份的 GitHub 日报：挑了 5 个普通人能用的项目。

最想推荐 Wealthfolio：把收支、预算和资产集中到一个地方看。适合想认真管钱、又不想维护 Excel 的人，电脑/自托管，AGPL-3.0。

另外几个：
· Super Productivity：待办 + 时间盒 + 时间追踪，手机/电脑，MIT
· OpenHabitTracker：记录习惯、看连续天数，手机/电脑/自托管，GPL-3.0
· mhabit：极简习惯打卡，支持同步，手机/电脑，Apache-2.0
· Tomato：一个安静的番茄钟，手机/电脑，GPL-3.0

每天自动更新，零依赖开源：https://daily-atk.github.io/github-daily-monitor/

求拍砖：你觉得「普通人能用」最该看什么——免费、手机能用，还是不用配置？
```

## 短版（忙的时候）

```
今天日报里最想推荐 {项目名}：{一句话功能}。{平台}，{许可证}。

完整日报：{链接}
```

## 周复盘模板（每周一条）

```
做 GitHub 日报第 {N} 天，本周被点开最多的是 {项目名}。

这周最大的感受：{一句真实的观察，例如“大家对‘手机上能直接用’最敏感”}。

下周想调整的关键词：{方向}。

日报：{链接}
```

## 配图建议

- 首图：当天日报首屏截图（`docs/screenshot.png` 更新版）
- 第二张：最推荐项目的卡片截图
- 不要用纯文字大图；即刻用户更吃“真实截图”

## 发布检查

- [ ] 开头 2 行内说清楚“今天推荐什么”
- [ ] 至少一个项目写了具体人群
- [ ] 每个项目有平台 + 许可证
- [ ] 结尾有一个真实问题，而不是“求关注”
- [ ] 链接可访问；如果不可访问，换成仓库链接
- [ ] 配图 1–3 张

## 不要做

- 用“重磅”“天花板”“必装”这类词
- 一次贴 10 个项目（没人看完）
- 只放链接、不写自己的判断
- 在多个圈子重复发同一条
- 要求点赞/转发

## 5 分钟流程

1. 打开当天 `reports/github-daily-{日期}.md`
2. 选 1 个主推荐 + 3 个补充
3. 主推荐写“适合谁 + 平台 + 许可证”
4. 配 1–2 张截图
5. 结尾抛一个问题，发布后回复评论
