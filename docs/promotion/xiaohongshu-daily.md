# 小红书日更模板

## 平台特点

- 标题 **≤20 字**；正文 **≤1000 字**；图片 1–9 张（建议 4–6 张）
- 正文里**不要放外链**，容易限流；仓库名写在正文，日报地址放主页/评论区
- 语气：口语、短句、多换行；少术语，多写“适合谁 / 能省什么事”
- 发布时间：19:00–22:00
- 标签 6–10 个

## 标题公式（选一个，≤20 字）

1. 今天挖到5个普通人能用的GitHub神器
2. 不写代码也能用的GitHub项目
3. 每天5个｜普通人也能用的开源工具
4. 别再刷GitHub Trending了
5. GitHub上那些普通人真能用的项目

## 配图建议

| 图 | 内容 |
|---|---|
| 封面 | 大字标题「今天 5 个普通人能用的 GitHub 项目」+ 日期 |
| 2–6 | 每个项目一张：项目名 + 一句话 + 平台/许可证 |
| 最后 | 日报截图 + 「每天更新」 |

封面建议用高对比色，项目卡片保持同一版式；可以直接从 `docs/screenshot.png` 裁切。

## 5 分钟日更流程

1. 打开 `reports/github-daily-{日期}.md`
2. 优先选：**平台明确（手机/网页）> 许可证清晰 > 上手难度低**
3. 复制模板，替换 5 个项目
4. 做 5 张项目卡片 + 1 张封面
5. 发布，评论区补一句「仓库名在正文，日报地址在主页」

## 不要做

- 正文放外链（限流）
- 写「最好用」「第一名」「保证」
- 推荐需要命令行/自托管且没写注意事项的项目
- 同一天重复发同一批项目
- 用未经验证的许可证或平台信息

## 发布检查

- [ ] 标题 ≤20 字
- [ ] 正文 ≤1000 字
- [ ] 5 个项目都写了平台和许可证
- [ ] 至少 1 个项目是「手机/网页直接用」
- [ ] 图片 4–6 张，封面有日期
- [ ] 标签 6–10 个
- [ ] 主页/评论区有日报地址
