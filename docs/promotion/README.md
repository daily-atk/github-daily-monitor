# 推广材料索引

按你选定的渠道整理，所有文案都可以直接复制使用。发布前请先确认目标读者能打开 Demo。

## 文件

| 渠道 | 文件 | 形式 | 备注 |
|---|---|---|---|
| HelloGitHub | [`hellogithub.md`](hellogithub.md) | Issue / 网站投稿 | 已按官方模板填好 |
| 掘金 / OSChina / Gitee | [`juejin-oschina.md`](juejin-oschina.md) | 技术长文 | 含 Gitee 镜像步骤 |
| Reddit | [`reddit-subreddits.md`](reddit-subreddits.md) | 四个 sub 的分版文案 | 一次只发一个版 |
| Hacker News | [`hacker-news.md`](hacker-news.md) | Show HN | 英文，技术受众 |
| Product Hunt | [`product-hunt.md`](product-hunt.md) | 产品发布 | 英文，需 logo/gallery |
| Twitter / X | [`twitter-thread.md`](twitter-thread.md) | 7 条 thread | 英文 |
| 小红书 | [`xiaohongshu-daily.md`](xiaohongshu-daily.md) | 日更模板 + 今日示例 | 5 个项目卡片，正文不放外链 |
| 知乎 | [`zhihu-daily.md`](zhihu-daily.md) | 想法日更 + 文章周更 | 长文吃搜索流量 |
| 即刻 | [`jike-daily.md`](jike-daily.md) | 日更短帖 + 周复盘 | 真实语气，结尾提问 |

另见 [`docs/launch/`](../launch/) 里的 V2EX、少数派、Reddit 通用稿和即刻可用素材。

## 推荐顺序

| 周 | 动作 |
|---|---|
| 第 1 周 | HelloGitHub 投稿 + 掘金技术文（先建立可信度） |
| 第 2 周 | Reddit（r/Python → r/github）+ HN Show HN |
| 第 3 周 | Product Hunt + Twitter thread |
| 持续 | 小红书/知乎/即刻日更；每期日报同步一条短内容 |

## 发布前统一检查

- [ ] Demo 在目标读者网络可访问（GitHub Pages 在国内可能不稳）
- [ ] 仓库 README 首屏有截图、一句话介绍、在线 Demo
- [ ] GitHub 仓库描述、Topics、Social preview 已设置
- [ ] `v0.1.0` tag / Release 已创建
- [ ] 截图和文案里的链接都是 `https://github.com/daily-atk/github-daily-monitor`
- [ ] 不包含 token、个人路径、未公开数据
- [ ] 每个平台按自己的语境改写开头，不直接复制粘贴

## 看什么指标

| 指标 | 怎么看 | 说明 |
|---|---|---|
| GitHub stars | 仓库首页 | 参考，不是唯一目标 |
| Issues / Discussions | GitHub | 真实反馈比 star 更有价值 |
| Demo 访问 | 可加隐私友好的统计（可选） | 判断普通读者是否真的在看 |
| RSS 订阅 | 如果加了 feed | 日报类产品最真实的留存指标 |
| 评论质量 | 各平台 | 有没有人问“怎么部署/怎么改关键词” |

## 不要做

- 买 star、刷榜、群发广告。
- 同一天把同一段文案发到所有平台。
- 承诺“每天 10 个精品”——项目定位是宁缺毋滥。
- 在无关群里硬发链接。
- 让朋友集中点赞/upvote（HN、Reddit、PH 都会识别）。
